选择 **File → Open Folder**，打开 `/Users/aaron/Desktop/港硕申请助手`。无需 npm 安装，使用 Node.js 24（支持原生 fetch、AbortSignal 和 --env-file）。

在 Cursor 终端运行：

```sh

```

访问 [http://127.0.0.1:8768](http://127.0.0.1:8768)。没有服务端密钥时，免费工具仍可使用，AI 显示“暂未启用”。结束时按 Ctrl+C。

```sh
node --env-file=.env.local scripts/dev.js
```

真实密钥只放在本地 `.env.local` 或 Vercel 服务端环境变量；不要贴到聊天、HTML、JS 或 GitHub。`.env.local` 已在 Git 忽略规则内。本地服务只监听本机地址，不能用 localhost 链接分享给别人。

## AI 交互与数据范围

打开面板仅向本站 `/api/chat` 检查配置状态；只有点击发送后，才将问题、最多三组最近成功对话及当前所选卡点交给 DeepSeek。总输入长度有限制，过长时移除较早的完整对话。没有材料文件上传；应用不写入聊天记录，刷新清空前端会话。

模型密钥只在服务端读取，官方请求地址固定。回答按纯文本显示。无密钥时禁用发送；调用失败、超时或频率过高时保留问题并给出提示。GET 检查配置不会调用模型。

未选择项目时，问答仍限定材料推进、本站说明与人工试点范围。选择项目后，只读取预置的三份公开官方页面；大学网站收到普通网页访问，不收到用户问题或对话。相关短条款与目标项目交给现有 DeepSeek 整理，不接入新的搜索服务、不需要新的 API 密钥。切换项目模式后，模型不再接收之前模式的对话，可见记录仍保留至刷新。

回答下方的来源由服务端实际读取结果提供，包含官网链接、读取时刻及当页适用年度；研究生院通用条款未单列年度时会明确标记。官方文本和先前聊天都作为低信任资料，不能更改助手规则。未公开的推荐人关系、职称和互相不一致的流程，保留待项目确认。模型整理仍需对照原文，不提供录取概率。

三个固定来源：[项目主页](https://www.idd.cuhk.edu.hk/mscgi/)、[项目申请要求](https://www.idd.cuhk.edu.hk/mscgi-application/)、[研究生院通用材料清单](https://www.gs.cuhk.edu.hk/admissions/documents-required)。2026-10-05 读取时，项目页面已明确 2027 入学与两位推荐人；未见推荐人关系或职称要求。项目申请页列推荐人直送或密封件，研究生院通用页列在线填写推荐人资料，须保留这项差异，不能直接认定全部在线完成。

每页读取量和整体读取时间有上限；公开条款可在当前实例缓存 15 分钟，来源时间显示实际抓取时刻。缓存不保存聊天，也不保证跨实例命中。无法取得完整官方资料时，不调用模型假装已经核对，而是提示稍后重试并保留问题。官网限制访问或改版后，需重新检查来源提取。

服务端有每 IP、每实例 10 分钟最多 20 次请求的限制，以及输入和输出长度、超时限制。该限制不能覆盖 Vercel 的所有并行实例，同源校验也不是用户身份验证；费用仍取决于真实调用量和服务商账户设置。

## 我的申请清单 · 单项目试点

打开 `progress.html`，先填学历授予地、毕业状态、专业与英语证明状态，再点击“建立我的清单”。页面依据 2026-10-05 读取的项目申请说明与研究生院通用材料页整理任务；通用页面未单列入学年度，其适用方式仍需向项目确认。每项任务保留官方链接和核查日期。推荐人职称与关系未明确，成绩单与推荐报告的项目邮寄要求和大学通用线上要求分别保留。

背景、任务状态与申请收件记录只保存在当前浏览器的独立 localStorage key；不上传证件或完整材料、不发送到模型、不跨设备同步。用户主动建立清单后，后续修改自动尝试保存；浏览器禁用存储或保存失败时显示未保存提示。相同协议、域名与端口下重新进入可恢复；更换浏览器、预览端口或清除网站数据后不会自动恢复。清除按钮仅删除本站这项清单记录，不清除其他网站数据。聊天仍按原方式刷新清空。

材料任务状态由用户记录：待准备、准备中、已准备、已提交、待学校确认。申请收件确认独立记录，不据此自动改变任何材料任务，也不等于录取或每份材料已收。AI 不读取或修改清单状态。内地学历显示毕业证及学信网验证任务；切换背景暂时隐藏不适用任务，但保留原有状态。拟用英语豁免不自动判定为达标。

项目申请截止为 2027-04-30。推荐报告须尽早抵达项目办公室，最迟按官网“申请截止后两周”计算为 2027-05-14；这是送达期限，不是只需在当日发出。页面按香港/北京时间日历展示临近截止、期限已过和下一步提示，仅在打开页面时计算，不发送邮件或推送。项目的其他材料邮寄时限与在读申请者安排尚待确认，不编造日期。

资料核查日期为本次整理公开官网的日期，没有后台自动巡检、人工服务审批或变更通知机制。十天后页面提示再次核对来源，不把旧资料写成已实时更新。人工核查、账号/云保存、跨设备使用及外部提醒渠道仍待另行确定。

## 免费工具和产品边界

免费定位不请求后端、不发送或保存选择。选好两项后，查看先做什么、找谁、完成依据，以及何时值得人工核对。可复制行动提示；咨询草稿可编辑、复制，不自动发送或保存。无 JavaScript 时仍可查看样例。

人工服务处于试点筹备阶段；人民币 199 元／次是尚待验证的拟试价，实际费用、交付日与反馈时间先确认。范围为 1 位申请者、1 个拟入学年度、最多 3 个已有候选项目与一次原项目、原清单反馈复核。

现有页面没有实际联系入口、材料上传、预约、支付、外部自动提醒或学校申请后台。新增个人清单只记录学生自述的材料状态。材料获取、联系学校与申请提交由学生自行完成，不保证录取。陈同学的背景、材料与进度全部虚构；样例中的学校资料仍沿用 2026-10-03 核对结果；本次官网联网仅涵盖上述港中大项目，未重核其它样例。

先让真实申请者使用免费入口，比较原有工具是否已解决问题、后续是否推进、人工是否补足具体证据，以及核对耗时。价格、获客方式和人工服务价值仍待验证。
