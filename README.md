多页面静态预览。面向已选好香港授课型硕士候选项目、被材料问题卡住的申请者。首次使用路径为：首页直接选择材料卡点 → 获取下一步 → 判断是否需要人工核对。

## 用 Cursor 打开

选择 **File → Open Folder**，打开 `/Users/aaron/Desktop/港硕申请助手`。入口是 `index.html`，无安装依赖或构建步骤。也可以双击 `index.html` 直接浏览。

如果希望在浏览器完整检查，打开 Cursor 终端，运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

然后访问 [http://127.0.0.1:8766](http://127.0.0.1:8766)。结束预览时在终端按 Ctrl+C。

## 上传 GitHub，再部署 Vercel

项目已包含 `vercel.json`：框架为 Other，构建命令为空，输出目录为 `.`。无需 npm 安装、构建或配置环境变量。已有 `.gitignore` 排除系统文件、`.vercel`、环境文件和日志。

1. 在 GitHub 新建一个仓库，可使用名称 `hk-masters-helper`，名称可自行调整。
2. 将本目录内的文件上传到仓库根目录。根目录应直接看到 `index.html`、`vercel.json` 和 `assets/`，不要再套一层“港硕申请助手”文件夹。保留 `assets` 内的 CSS 和 JS。
3. 在 Vercel 选择 **Add New → Project**，导入该 GitHub 仓库。**Root Directory** 保持仓库根目录。项目配置会按 `vercel.json` 使用 Other、跳过构建、输出 `.`；如界面手动指定了设置，请核对是否与此一致。
4. 点击 **Deploy**。得到 HTTPS 网址后，检查首页两项选择和行动提示复制、手机菜单、样例切换，以及咨询草稿复制。
5. 后续向已关联的仓库生产分支提交更新，Vercel 会触发新的部署。

官方说明：[从 Git 导入部署](https://vercel.com/docs/git)、[静态配置文件](https://vercel.com/docs/project-configuration/vercel-json)、[纯 HTML/CSS/JS 跳过构建](https://vercel.com/docs/builds/configure-a-build#skip-build-step)。

## 当前产品边界

- 人工试点筹备阶段；人民币 199 元／次为尚待验证的拟试价，实际费用、交付日与反馈时间先确认。
- 范围为 1 位申请者、1 个拟入学年度、最多 3 个已有候选项目与一次原项目、原清单反馈复核。
- 现有网页支持查看、页面跳转、菜单、折叠资料、免费卡点定位、行动提示复制与咨询草稿复制。没有实际联系入口、材料上传、预约、支付、自动提醒或申请后台。
- 草稿不自动发送或保存。材料获取、联系学校与申请提交仍由学生自行完成；不保证录取。
- 陈同学的背景、材料与进度全部虚构。学校资料沿用 2026-10-03 核对结果，本次改版未重新核实；方案更新日为 2026-10-04。

## 免费入口怎样使用

1. 打开首页，在免费工具面板中开始选择；咨询页也保留同一工具。
2. 选择正式文件、官方条款冲突或推荐报告收件问题，再选择当前状态。
3. 点击“查看下一步”，获取先做什么、找谁、完成依据及何时值得人工核对。
4. 可单独复制行动提示；咨询页草稿仍可编辑，不会被免费结果覆盖。

提示依据用户选择给出通用准备行动，不进行逐项目资料查证，不认定材料合格或大学已收件。页面不请求后端、不保存输入；关闭或刷新前请自行保留所需文字。无JavaScript时可继续查看样例。

## 试点价值怎样验证

先让真实申请者使用免费入口，记录卡点、原先用过的官网/GPT等工具、后续是否推进以及人工核对耗时。199元价格、人工相对免费工具的价值、获客方式仍待验证。比较同一个真实任务，观察人工核对是否补足了具体证据或材料对应，而非仅增加文字。
